# 📻 РадоФМ

Самостоятельное графическое интернет-радио для Linux (Void/Hyprland и другие).
Тёмный интерфейс, список станций (SomaFM), воспроизведение через внешний mpv.

## Запуск

```bash
cd ~/radiofm
python3 main.py
```

Сборка не требуется. Зависимости (обычно уже установлены):
`python3-pyside6`, `mpv`. Проверить: `python3 -c "import PySide6"` и `mpv --version`.

## Как пользоваться

- клик по станции в списке — запуск;
- большая кнопка — пауза/продолжить (при подключении — отмена), ▮ — стоп;
- ползунок — громкость;
- при обрыве/ошибке показывается сообщение, кнопка ▶ повторяет попытку;
- «сейчас играет» берётся из метаданных потока (icy-title).

## Станции

Список — `stations.json` в каталоге проекта, формат JSON (редактируется руками):

```json
{ "id": "groovesalad", "name": "Groove Salad",
  "description": "...", "url": "https://ice1.somafm.com/groovesalad-128-mp3" }
```

Изменения подхватываются при следующем запуске.

## Настройки

`~/.config/radiofm/radiofm.conf` — последняя станция, громкость, размер окна.

## Самопроверка

```bash
python3 smoke_test.py
```

Проверяет список станций, сборку окна (offscreen), реальное воспроизведение
потока без звука (ao=null), паузу/стоп, отсутствие фоновых процессов mpv и
запись настроек.

## Удаление

```bash
rm -rf ~/radiofm ~/.config/radiofm
```

Система не изменяется: пакеты не ставились, конфиги рабочего стола не трогались.

## Структура

```
main.py          точка входа
radio/engine.py  AudioEngine: mpv + JSON IPC (аудио отделено от UI)
radio/ui.py      окно Qt (список + плеер)
radio/stations.py работа со станциями
stations.json    список станций
smoke_test.py    самопроверка
```

Ограничения MVP: нет визуализаторов (этап E), нет автопереподключения при
обрыве (нужно нажать ▶), один процесс mpv живёт до закрытия приложения
(штатное закрытие гасит его начисто; при kill -9 возможен короткоживущий
остаток до 15 сек — network-timeout).
